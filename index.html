CORELink

Bridges guild chat between co-guilds in World of Warcraft: Forever. One addon folder, no setup for members.

Download RC

For guild leads testing the next version. Published 2026-11-15. Report problems with /cl report.

What's new in 0.2.1

▎ Two fixes for the live link. When a player in a linked guild logs off, CORELink no longer shows "No player named … is currently playing" for every carried line; it stops whispering that player and sends the line to another addon user in their guild. Guilds with a guilds= list on their Guild Info line no longer get "Interface action failed because of an AddOn": the lookup that caused it is removed, and guilds= is now ignored. Nothing changes on the wire, so 0.2.0 and 0.2.1 clients keep working together.

Install

  1. Unzip. You get a folder named CORELink.
  2. Move it into World of Warcraft/_forever_/Interface/AddOns/, replacing any older CORELink folder.
  3. Log in, or type /reload if you were already in game. Type /cl report: the first words are the version you are running.

If your guild's Guild Information already has a CORELink: line, you are done. Guild masters: /cl setup <channel> <password> [tag] and paste the line it shows into Guild Information.
