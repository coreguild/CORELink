Install

  1. Unzip. You get a folder named CORELink.
  2. Move it into World of Warcraft/_classic_beta_/Interface/AddOns/, replacing any older CORELink folder.
  3. Log in, or type /reload if you were already in game. Type /cl to confirm the version.

If your guild's Guild Information already has a CORELink: line, you are done. Guild masters: /cl setup <channel> <password> [tag] and paste the line it shows into Guild Information.
